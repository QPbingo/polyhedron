# 多面体 V1 交付验证

日期：2026-09-09（Asia/Shanghai）。本次交付是可本机运行的前后端实现，以及正式部署和 macOS 打包工具。云部署、真实身份提供方登录和签名发行仍需外部配置与验收。

## 实现范围

- `frontend/`：独立 React/Vite 工程，保留已确认的项目树、项目内新建、右侧满屏终端和六套配色。真实登录、主机配对、会话接管、搜索/筛选、重命名、历史运行选择、归档和恢复入口。
- `backend/`：独立 Node/TypeScript 工程。Session Host 持有原生 PTY、终端状态和 SQLite；连接服务与账号中继独立运行，关闭浏览器或重启连接/中继不结束 Agent。
- 正式中继使用 PostgreSQL、OIDC、HTTPS/WSS、HttpOnly Cookie、CSRF/Origin 校验、单次配对和短期签名授权。授权包含账号、主机、标签页、方法及会话/运行范围。支持解绑主机及撤销其他浏览器登录。
- 主机验证真实目录与授权根目录、单端操作权、运行/控制代次及输入序号。输入不自动重发；原生 CLI 的登录、目录信任和工具审批原样保留。
- 本地历史分段保存，默认 30 天 / 128 MiB；运行中的最新恢复快照可保留在配额之外。中继只持久保存必要账号/绑定数据与经过字段筛选的离线摘要，不保存项目路径、原生会话 ID、终端正文或 Hook 内容。
- macOS 提供 Keychain 配对、双 LaunchAgent 生成/安装、独立 Node 下载、未签名打包及显式签名公证脚本。

## 尚需外部验收与明确限制

1. 真实 OIDC 租户、域名/TLS 网关、生产 PostgreSQL 备份与正式跨 PC 登录。中继当前为单实例连接注册表，多实例横向扩展需要额外协调。
2. 用户完成原生信任和厂商登录后，实际 Codex/Claude 任务、工具审批 Hook、精确原生 ID 恢复及升级后的兼容性验收。启动到信任屏不等于完整模型任务通过。
3. 两台物理 PC、Safari/Edge、实际中文 IME 与剪贴板矩阵、长时运行、弱网、10 个混合 Agent 的 30 分钟性能与资源验收。本次没有宣称相应性能指标达标。
4. 真机 Keychain 交互、LaunchAgent 安装/重启、全新 Mac 安装、Apple 签名/公证与签名后 Node JIT/PTY 验证。当前仅提供未签名 arm64 安装包，没有安装全局服务。
5. 重连恢复采用主机权威完整快照；在线输出是增量流。跨连接按序号补发增量尚未实现。历史受保留策略约束，不是无限存储。
6. 为区分真实键盘输入和终端协议查询回复，前端固定 xterm 5.5.0，并隔离使用内部输入来源标记；升级必须重测，接口失配会禁止输入。OSC52 关闭，HTTP(S) 终端链接需用户确认。

使用命令、生产配置和数据位置见 [项目 README](../../README.md)。
